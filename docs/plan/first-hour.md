# 첫 60분

시간은 작업 시작 이후 상대 시간이다. 사용자 최신 지시에 따라 실제 연결 대신 Adapter 계약과 전체 흐름을 우선한다.

| 구간 | 실행 | 완료 증거 |
| --- | --- | --- |
| 0–5분 | 문서 저장·재읽기·Git 상태 | 실제 파일과 검증 결과 |
| 5–15분 | 신청·귀속·기존 신청자·측정 기간 계약 | 설정과 MeasurementAdapter 정의 |
| 15–30분 | 조사·배포·승인 Adapter 설계 | 실제 근거와 미연결 상태 분리 |
| 30–40분 | 한국어 공개 콘텐츠 초안 하나와 루프 구현 | asset_id, CTA, 검토 상태 |
| 40–50분 | 승인·게시 영수증·불확실 결과 처리 | 합성 검증; 실게시 여부 별도 |
| 50–60분 | 성과·다음 변경·실행 기록·Git | 첫 실행, 다음 실행 제안 |

실연결 시 원래 순서: 신청 목적지/접수 검증 → 공개 고객 원문과 접근 가능한 배포 후보 최대 10개 → 콘텐츠 검토 → 계정·승인 준비 시 게시 → 성과 수집.

막힌 정보와 독립 작업은 함께 기록하고 가능한 일을 계속한다. 스케줄러 연결 전에는 수동 실행이며 담당·시각은 제안과 확정을 구분한다.
