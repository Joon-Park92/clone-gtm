## 기록 방식

각 후속 항목에는 계획/변경 이유 → 실제 수행 → 결과/미실행 사유 → 증거 경로 → 다음 행동을 남긴다. 실제 실행 시각은 시간대와 함께 기록하고, 완료되지 않은 계획을 실행으로 표시하지 않는다. 외부 게시에는 승인한 버전·계정·채널과 게시 URL·시각이 필요하다. 개인정보·원본 신청 자료는 Git에 넣지 않는다. 과거 실행 파일을 덮어쓰지 않고 후속 수정은 새 기록으로 연결한다.

## E007 — 신규 배포 설계 통합

계획: 기존 계정·독자 없이 첫 모집 경로를 정한다. 실제 수행: 고객·채널 담당이 현재 공식 가입·운영 안내를 확인했고, 콘텐츠 담당이 프로필·제품 등록 원고·고객 질문을 추가했다. 메인이 과거 메이커로그 제안을 갱신하고 제목 코드 CTA와 일치하도록 통합했다.

결정: Disquiet 제품 등록 검토 후 연결 포스트를 주경로로 제안. 검토 요청 후 24시간 미승인 또는 사전 출시 제품 부적격이면 Threads 대안을 검토한다. 이 시간은 운영 제안이고 플랫폼 처리 시간 보장이 아니다. 신규 계정·노출·신청은 아직 없다. 사용자 승인 전 외부 실행하지 않는다.

검증: 문서 재읽기, 공개 본문·설정 해시 일치, JSON과 로컬 링크 확인. 다음 행동: 준비된 계정·제품 등록 문안을 사용자가 검토할 수 있도록 유지하고, 실제 계정·채널이 정해진 시점에 최종 공개본을 승인받는다.
