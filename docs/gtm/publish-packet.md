- 별도 제목: 없음
- 첨부물: 없음
- 제품 링크: https://mu.pairful.ai/ko
- asset_id: MU-KO-001-A-d1e4e4572d84a75a
- content_sha256: d1e4e4572d84a75a1bfc2d1989b7e1000eec979afcc32938330c8bce64ca8545
- 승인 상태: pending
- 게시 URL·시각: null

해시는 위 공개 본문만 UTF-8로 계산하고 끝 개행과 주석을 제외한다. config.draft.body와 동일하다. 계정·내용·첨부물·링크·대상이 변경되면 최종본 전체를 다시 보여주고 명시적인 승인을 받는다. 기존 Disquiet 초안의 asset_id나 승인을 재사용하지 않는다.

## 신청 제목 코드 설명과 남은 결정

[MU-KO-001]은 내부 캠페인 식별자다. MU는 제품, KO는 한국어 캠페인, 001은 첫 캠페인이다. 사전 입력된 메일 제목으로 이번 홍보에서 유입된 신청을 구분하려고 제안했다. 신청자에게 번호를 주거나 할인·혜택을 제공하는 코드가 아니다.

사용자가 의미를 질문했으므로 설명 요청 상태로 두며 적용에 동의했다고 간주하지 않는다. 이 Threads 초안에는 코드를 넣지 않았다. 현재 랜딩의 신청 버튼은 코드 없는 메일 제목을 열기 때문에, 이 초안 그대로는 캠페인 귀속을 보장하지 못한다. 게시 전 제목 자동 입력 방식 또는 유입 경로 자기보고 중 실제로 쓸 방법을 확정해야 한다. 수신 검증 전 attribution.verified=false를 유지한다.

[메일 제목 코드 설계](attribution-setup.md)는 선택 가능한 준비안이다. Threads에서 mailto 링크가 동작한다고 가정하지 않는다. 링크의 동작과 가입 절차는 실제 계정 환경에서 확인한다.
