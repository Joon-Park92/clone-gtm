# EXP-MU-KO-001

campaign_id: MU-KO-001
상태: 인기 식당·모바일 앱 자동화 방향 확정, 실제 고객/전환 검증 전.
전략 원본: [ICP와 GTM 전략](strategy.md). 측정 정의: [측정 계약](measurement.md).

- ICP: 인기 식당 예약을 위해 모바일 앱에서 날짜·시간·인원 조건을 확인하는 모임 예약 담당자.
- 고객 문제: 앱을 직접 열고 조건을 입력해 예약 가능 여부를 확인하는 수고.
- 핵심 가치: 카카오톡으로 요청하면 Mu가 모바일 앱 안의 조회·조작을 수행하는 사용 방식.
- 첫 검증 질문: 이 수고를 맡기고 싶은 사람이 준비 단계임을 알고도 사전 사용을 신청하는가?
- CTA: 사전 사용 신청. 실제 이용·결제 전환이 아님.
- 유입 목적지: https://mu.pairful.ai/ko
- 배포: 문제와 참여 규칙이 확인된 접근 가능한 공개 채널 하나. 실제 채널·계정 미정.
- 주 지표: 7일 캠페인 귀속 중복 없는 신규 사전 신청자 수.

## 첫 콘텐츠 초안

“이번 토요일 저녁, 두 명 예약 가능한지 확인해줘.”

모바일 앱에서 해야 하는 일, 이제 카카오톡으로 부탁하세요.
Mu는 앱을 직접 열고 조작하는 개인 비서입니다. 식당 예약 확인부터 배송 조회, 장바구니 담기까지.

현재 사전 사용 신청을 받고 있어요.
Mu 사전 사용 신청 안내: https://mu.pairful.ai/ko

## 검토 상태

초안이며 게시 승인 전. 사용자의 제품 설명에 근거하고 실제 데모 검증 전이다. 실제 지원 범위·신청 목적지·접수 확인과 계정/채널/본문 승인이 필요하다. 특정 예약 서비스가 모바일 전용이라고 단정하지 않는다. 예약 성공·좌석 선점·즉시 사용·자동 반복 감시를 약속하지 않는다.

## 변경 기록

2026-10-24: 사용자가 인기 식당을 첫 사례로 선택하고 모바일 앱 자동화를 핵심 가치로 지정했다. 최초 게시 전 전략 구체화이며, 관측 결과를 바탕으로 한 최적화나 A/B 테스트가 아니다. 기존 한국어 식당 가설의 experiment_id를 유지한다.

메시지 합의: 인기 식당 예약 확인은 첫 관심을 만드는 사례이고, 제품 정체성은 범용 모바일 앱 자동화 비서다. 사용자가 이 메시지 방향으로 루프 설계를 승인했다. 계정·채널을 포함한 실제 게시 승인은 아직 없다. 실행 설계는 [첫 루프](../plan/first-loop.md)를 따른다.
