# 가설·콘텐츠·계정별 배포를 분리한 실험 포트폴리오

사용자 요구에 따라 단일 음식 예약 실험을 여러 가설·운영 계정의 병렬 실험으로 확장한다. 캠페인 귀속만으로는 실험군 비교가 불가능하므로 가설 버전·콘텐츠·계정별 배포·실제 신청을 별도로 연결하고, 귀속이 검증되지 않으면 보상 학습과 운영 승자 판정을 보류한다. 생성·검토 에이전트의 Rubric은 버전으로 교체하되, 검토 점수를 신청 보상에 넣지 않고 계정·시각 차이와 전환 지연을 보존한다.

기존 단일 게시 조정 코어는 배포 실행 계약으로 유지한다. 새 포트폴리오 코어는 여러 배포 슬롯의 선택과 가설 계보를 담당하며, 실제 모델·외부 게시·메일·스케줄 연결은 Adapter로 남긴다.
