# 첫 고객·채널 조사

조사일: 2026-10-24, Asia/Seoul. campaign_id: MU-KO-001 / experiment_id: EXP-MU-KO-001.
기준: [GTM 전략](../../PRESENTATION.md), [첫 루프](../gtm/portfolio-loop.md).
범위: 공개 원문 3건과 배포 후보 3곳. 검색 결과의 수를 고객 수로 계산하지 않았다. 고객에게 연락하거나 댓글·게시·가입을 실행하지 않았다.

## 결론

**앱을 반복해서 열고 날짜·예약 상태를 확인하는 행동은 관찰했다. 그 수고 때문에 조회를 Mu에 맡기거나 사전 신청하겠다는 의사는 아직 확인하지 못했다.** 현재 세 가지 고객 조건과 배포 조건을 모두 통과한 후보는 0개다. 이는 제한된 이번 조사에서의 미확인이며 시장에 고객이 없다는 뜻이 아니다.

오마카세 갤러리는 고객 맥락이 가깝지만 광고 금지 공지가 있어 직접 홍보 후보에서 제외한다. 더쿠 음식먹방은 규칙을 확인하지 못해 대기한다. 디스콰이엇은 제품 공유 방법을 안내하지만 인기 식당 예약 ICP가 실제로 있는지는 미확인이다. 따라서 **이번 조사만으로 즉시 게시할 채널을 확정하지 않는다.**

## 다음 채널 행동

1. **다음 읽기 조사 대상은 디스콰이엇으로 한정한다.** 제품 공유 안내가 있어 접근 경로를 구체화하기 쉽다는 운영상 판단이다. ‘예약 확인을 앱에서 하는 사람’이 포함된 실제 대화가 있는지와 적합한 공개 작성 형식을 확인한다. 아직 이곳을 첫 식당 ICP 채널로 확정한 것은 아니다.
2. 기존 접근 가능한 맛집/모임 커뮤니티가 사용자에게 있다면, 링크·참여 규칙·예약 조회 불편 원문이 확인된 한 곳을 우선 검토한다. 새 계정의 자연 유입은 가정하지 않는다.
3. 후보에서 확인할 최소 질문을 문안에 준비한다: ‘예약 가능한 시간을 확인할 때 어떤 앱 작업이 가장 번거로운가요?’ 실제 질문 게시·연락은 구체 채널과 본문 승인을 받은 뒤 수행한다.
4. 답변이 좌석 확보·경쟁 속도에만 집중되면 조회 위임 ICP로 승격하지 않는다. 앱 조작 수고를 설명하고 사전 사용에 관심을 표현하는 경우에만 적합성을 높인다. 실제 신청 접수 전에는 주 지표로 세지 않는다.

## 루프에 반영할 관측과 해석

- 관측: 예약을 위해 앱을 반복 확인하는 행동을 기술한 공개 글이 있다.
- 해석: 제안한 사용 상황이 현실에 존재한다는 제한적 근거다. Mu의 조회 위임 가치가 충분히 큰지, 준비 단계의 제품에도 신청할지는 미확인이다.
- 유지할 것: 인기 식당 사례 → 범용 모바일 앱 자동화 비서 → 사전 신청이라는 합의한 메시지.
- 다음 주요 변경: 아직 메시지를 성과 기반으로 바꾸지 않는다. 배포 후보의 고객 적합성·게시 가능성 확인을 우선한다.
- 미측정: 노출, 방문, 신청, Mu 사용 의사. 모두 성과 0으로 기재하지 않는다.

## 출처 확인 방법

웹 도구로 공개 원문 본문을 조회했다. 출처별 내용을 짧게 요약했으며 전문·사용자 식별정보를 저장하지 않았다. 검색 요약만 보인 SEO성 가이드, 타 사이트 리뷰 재전재, 일반 서비스 소개는 실제 고객 수요 근거에서 제외했다. 공식 플랫폼 규칙과 개인 고객 경험은 서로 다른 근거로 관리한다.

현재 코어는 observed 신호에 problem_observed=true를 요구한다. 따라서 이 결과를 거짓 true로 변환하지 말고 **research.status=pending**과 문서 참조로 연결한다. 조사를 수행했으므로 ‘조사 미실행’과 혼동하지 않도록 실행 기록에 ‘공개 조사 완료, 적격 고객 근거 추가 확인 대기’라고 남긴다.

## 후속 확인 — 현재 운영 규칙 우선

2026-10-24 계정·독자 0 배포 설계 중 [디스콰이엇 현재 공지](https://disquiet.io/announcement)를 추가 확인했다. 기존 메이커로그 신규 작성이 중단되어 앞의 2024 가이드를 현재 게시 절차로 사용하면 안 된다. 현재 후보 경로는 본인 제품 등록·검토·승인 후 제품 연결 포스트다. 가입 화면은 https://disquiet.io/signup 에서 확인했다. 이 발견은 기존 메이커로그용 초안의 게시 형식 가정을 수정하며, 고객 적합성·노출은 여전히 미확인이다. 최신 결정은 [계정·독자 0 배포 설계](../gtm/publish-packet.md)에 둔다.
