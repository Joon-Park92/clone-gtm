# 해커톤 GTM 루프 운영 및 시상 요구사항

출처: 사용자가 제공한 Tiro 녹취 「해커톤 GTM 루프 운영 및 시상 가이드」. 생성 시각 2026-10-24T06:49:14.370Z. 아래는 녹취 요약이며 공식 공지를 별도로 조회한 결과가 아니다. 후반 B 발언은 전사 품질이 낮아 요구사항의 근거로 사용하지 않는다.

## 해야 할 일

1. 기존 제품 또는 현장에서 만든 제품으로 실제 고객에게 마케팅한다.
2. 제품 특성에 맞는 집중 지표 하나를 정하고 그 지표를 개선하는 GTM 루프를 설계한다.
3. 고객과 실행 조건을 에이전트가 확인할 수 있는 명시적인 조건으로 정리한다.
4. 현장에서 설계한 루프를 이후 정확히 7일간 실행한다.
5. Discord에 성과 설명, 숫자, 객관적인 증거를 제출한다.

## 본상

실제 GTM 결과에 대한 평가다. 진행자의 표현은 ‘정량 지표에 대한 정성 평가’이며 단순 숫자 순위나 공식 배점은 제시되지 않았다. 제품이 B2B/B2C인지, 소프트웨어/하드웨어인지 등 특성에 맞는 집중 지표를 택한다. 녹취상 OpenAI 크레딧은 1등 $15,000, 2등 $10,000, 3등 $5,000, 총 $30,000이다.

## Cloneist 특별상

본상과 별도이며 당일 수상자 1명 발표 예정. Clone 앱을 활용한 GTM 접근의 참신함을 평가하며 숫자 중심 기준이 아니다. 녹취상 상품은 Cloneist 플랜 1년 구독권과 merchandise 세트다. 모든 참가자는 어떤 AI든 사용할 수 있으며, Clone 사용이 본상 필수 조건이라고 말하지 않았다.

## 일정과 미확인

진행자는 현장 시작을 15:38로 말하고, 제출 링크 마감을 17:30에서 **17:38**로 정정했다. 현장 제출 링크의 실제 주소, 정확한 7일 측정 시작/종료 시각, Discord 제출 채널·양식, 최종 공지 변경 여부는 확인되지 않았다. 7일 후 제출과 당일 링크 마감을 혼동하지 않는다.

## Mu 설계에 적용

- 집중 지표: 캠페인에 귀속되는 중복 없는 신규 사전 신청자 수.
- 하루 한 번 이전 결과를 읽고 주요 조건 하나를 바꾸는 반복 구조.
- 초안·합성 테스트·에이전트 자체 평가는 실제 트랙션으로 제출하지 않는다.
- 제출 증거: 실게시 URL·시각, 실제 접수 기반의 중복 제거 집계, 제외 기준, 정제된 증거, 변경 이력.
- Adapter 구현을 미루는 현재 설계는 준비 단계다. 7일간 실제 고객에게 도달하고 측정하는 운영이 본상 결과를 만든다.
