## 제품

사용자 제공 설명: Pairful Mu는 카카오톡/iMessage로 앱 작업을 부탁하는 비서. 약 80개 앱, 쇼핑·예약·교통·지도 등을 소개한다. 배송 조회, 식당 예약 가능 여부, KTX 잔여 좌석, 장바구니, 메일 요약이 예시다. 결제·예약 확정은 승인을 요청한다고 소개한다. 실제 기능·데모는 검증하지 않았다.

사용자 확인: 현재 사전 신청만 가능하며 이메일 문의 후 순차 연락 방식이다. 홍보 계정은 없으며 필요하면 만들 의향이 있다.

제품 페이지: https://mu.pairful.ai/ko · https://mu.pairful.ai/en · https://mu.pairful.ai/ja

2026-10-24 이 세션 웹 도구로 세 페이지를 열었으나 모두 본문 접근 실패. 도구 접근 실패이며 서비스 장애라는 증거는 아니다. 실제 신청 버튼 목적지/이메일 주소는 확인하지 못했다.

## 최신 결정

메일함은 MCP 접근 가능으로 가정한다. 구체 인프라는 설정 파일과 Adapter로 추상화하고 구체 구현은 미룬다. 전체 루프 설계 완성이 제1원칙이다. 이 가정은 연결·수신·측정 완료를 뜻하지 않는다.

로컬 문서·설계·구현·조사·초안은 승인됨. 외부 게시, DM, 이메일 발송, 유료 집행, 원격 공개·배포는 승인되지 않았다.

## 환경
